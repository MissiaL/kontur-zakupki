# kontur-zakupki

Навык агента для External API Контур.Закупок: поиск тендеров, карточки закупок,
результаты, избранное, метки и лимиты. Подходит для клиентов с поддержкой
Agent Skills. Все девять операций приложенной спецификации доступны через CLI.
API используется для чтения данных; `POST /external/v1/search` выполняет поиск.

## Установка

Для Codex:

```bash
git clone https://github.com/MissiaL/kontur-zakupki.git ~/.codex/skills/kontur-zakupki
```

Для Claude Code укажите `~/.claude/skills/kontur-zakupki` как каталог клонирования.
Для другого агента поместите репозиторий в его каталог навыков.

Нужен Python 3.10 или новее. Внешние зависимости не требуются.
Точка входа агента — [SKILL.md](SKILL.md), параметры API —
[references/api.md](references/api.md), схемы —
[OpenAPI JSON](references/zakupki.external_api-api.json).

## Ключ и первый запрос

Получите ключ в [Кабинете интегратора Контура](https://integrations.kontur.ru/)
после предоставления доступа к API Контур.Закупок. Настройте переменную окружения
`KONTUR_ZAKUPKI_API_KEY` через окружение агента или менеджер секретов.
[.env.example](.env.example) показывает имя переменной; CLI не загружает `.env`.
Не добавляйте рабочий ключ в репозиторий и не передавайте его в аргументах CLI.

Из каталога репозитория:

```bash
# Без ключа и сетевого запроса.
python3 scripts/api_call.py --url /external/v1/limitGroups --dry-run

# С настроенным ключом.
python3 scripts/api_call.py --url /external/v1/limitGroups
```

Пример запроса агенту:

> Используй $kontur-zakupki: найди закупки по поставке оборудования,
> опубликованные с 1 по 7 октября 2026 года по московскому времени.
> Покажи заказчиков, цены, сроки подачи заявок и ссылки.

Период в примере фиксированный. Для нового поиска задайте нужные даты.
Рабочий ключ определяет доступные методы и квоты; каждый запрос может расходовать
квоту. Клиент не делает автоматических повторов и не следует перенаправлениям.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

Тесты проверяют подготовку запросов, авторизацию, ошибки и запрет
перенаправлений; внешние API не вызываются.

## Источники и границы проверки

Навык создан 19 октября 2026 года по JSON, предоставленному пользователем:
OpenAPI 3.0.4, версия API 1.0.0, девять операций.
[Портал документации](https://developer.kontur.ru/doc/zakupki.external_api)
при проверке перенаправил на авторизацию. Актуальность схем относительно
закрытого портала и реальные ответы API не подтверждены.
