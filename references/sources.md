## Обновление

Получите свежий экспорт OpenAPI из официального портала с разрешённым доступом.
Сравните сервер, заголовок авторизации, методы, обязательные поля, регистр имён,
перечисления и ограничения. Замените снимок, обновите затронутые инструкции,
проверьте совместимость `scripts/api_call.py` и выполните:

```bash
python3 -m unittest discover -s tests -v
```

Запишите дату, контрольную сумму нового снимка и результат проверки.
Не объявляйте реальные вызовы проверенными на основании одних локальных тестов.
