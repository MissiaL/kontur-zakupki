# External API Контур.Закупок

Основано на приложенном OpenAPI 3.0.4, версия API 1.0.0.
Базовый адрес: `https://api-zakupki.kontur.ru`.
Авторизация: заголовок `X-Kontur-Apikey`, без префикса `Bearer`.

## Методы

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/external/v1/limitGroups` | Лимиты по группам методов и сроки подписки |
| GET | `/external/v1/limits` | Устаревший общий суточный лимит |
| POST | `/external/v1/search` | Поиск по периоду публикации и фильтрам |
| GET | `/external/v1/purchases/{id}` | Полная карточка закупки |
| GET | `/external/v1/results/{id}` | Протоколы, проекты контрактов и контракты |
| GET | `/external/v1/favorites` | Избранные закупки за период добавления |
| GET | `/external/v1/markers` | Имена и идентификаторы меток пользователя |
| GET | `/external/v1/testpurchases/{id}` | Тестовая карточка из фиксированного набора |
| GET | `/external/v1/testfavorites` | Тестовое избранное |

`id` — строковый идентификатор Контур.Закупок, включая ведущие нули, дефисы
и подчёркивания. Используй `Id`, полученный от API; номер на ЭТП может отличаться.
`results` также поддерживает демонстрационный набор, отдельного пути `testresults` нет.

## Поиск

Тело — объект `ExternalApiSearchArgs`. Обязательны `DateTimeFrom` и `DateTimeTo`:
даты **публикации**, а не добавления в избранное или окончания подачи заявок.
Передавай дату и время в ISO 8601 с `Z` или смещением UTC.

| Поля | Тип и смысл |
|---|---|
| `Text`, `Exclude` | Массивы строк: ключевые слова и исключения |
| `IncludeInns`, `ExcludeInns` | Массивы строк: ИНН заказчиков для включения и исключения |
| `ParticipantsInns` | Массив строк: ИНН участников, победителей или поставщиков; тариф «Поиск 2.0» |
| `ParticipantsState` | Число: 1 — победитель, 2 — поставщик, 3 — все участники |
| `EnableParticipantsFromDocuments` | Boolean: поиск участников в документах; тариф «Поиск 2.0» |
| `RegionIds` | Массив UUID, не числовые коды регионов |
| `PurchaseStatuses` | Массив чисел: 1 — подача заявок, 2 — комиссия, 3 — завершены, 4 — планируются, 5 — отменены, 6 — несостоявшиеся |
| `Laws` | Массив чисел: 1 — 44-ФЗ, 2 — 223-ФЗ, 3 — коммерческие и малые, 5 — 615-ПП, 8 — коммерческие, 9 — малые |
| `Procedures` | Массив чисел: 0 — электронный аукцион, 1 — запрос котировок, 2 — единственный поставщик, 3 — конкурс, 5 — запрос или мониторинг цен, 99 — другие |
| `ElectronicPlaces` | Массив целочисленных идентификаторов ЭТП |
| `CategoryIds` | Массив целочисленных идентификаторов отрасли; список в описании `ExternalApiSearchArgs.properties.CategoryIds.items` |
| `Categories` | Устаревший массив значений `ApiSearchCategory`; предпочитай `CategoryIds` |
| `StrictSearch`, `Attachments` | Boolean: точный поиск и поиск по документам |
| `MaxPriceFrom`, `MaxPriceTo` | Целые числа: диапазон начальной цены |
| `MaxPriceNone` | Boolean: включать закупки без начальной цены |
| `Advance44`, `Advance223`, `NonAdvance` | Boolean: фильтры аванса для 44-ФЗ, 223-ФЗ и отсутствия аванса для других торгов |
| `Smp` | Число: 0 — не учитывать, 1 — только СМП, 2 — без СМП |
| `AllowForeignCurrency` | Boolean: включать закупки в валюте |
| `PageNumber` | Целое неотрицательное число: номер страницы |
| `ApplicationDeadlineFrom`, `ApplicationDeadlineTo` | ISO 8601: отдельный диапазон окончания подачи заявок |

UUID региона найди в [каталоге регионов](https://zakupki.kontur.ru/Region/Catalog).
Не подставляй в `RegionIds` коды вроде 77 или 78 и не выдумывай UUID.

В ответе схема `SearchResultItemPagingModel`: `PageNumber`, `TotalCount`, `Items`.
Элементы содержат `Id`, `NotificationNumber`, `OrderName`, `MaxPrice`, `Currency`,
`Link`, `ApplicationDeadline`, `Customers`, признаки отмены и другие поля.
`Items` может быть `null`. Условия поиска могут возвращать вариант со сниппетами.

Одна страница содержит до 50 закупок и расходует один поисковый запрос.
Начни с `PageNumber: 0`; следующие страницы запрашивай с теми же фильтрами.
Останавливайся по `TotalCount` или пустой странице. Если выдача прервалась,
сохрани последний номер страницы и обозначь результат как частичный.
Для одного диапазона дат доступно не более 10 000 закупок. Деление периода
может создавать пересечения: устраняй дубли по `Id`, сохраняя границы периодов.

## Избранное и метки

Параметры `favorites` и `testfavorites`:

- `dateFrom` обязателен: время добавления в избранное, включительно.
- `dateTo` необязателен: верхняя граница, не включительно.
- `markersNames`: массив из не более 100 **названий** меток, не UUID.
  На проводе: `markersNames=Интересно&markersNames=Участвую`.
  Без фильтра возвращаются все избранные закупки периода, включая закупки
  только с назначенным ответственным.
- `page`: номер страницы, начиная с 0; по 50 закупок.
- Только для `favorites`: `sortOrder` — число от 0 до 7. По умолчанию
  сортировка по окончанию подачи заявок, от срочных. Точные значения
  смотри в `components.schemas.ApiFavSortOrder`.

Ответ `FavoritesApiModelPagingModel` содержит `Items` с полями `Id`, `MarkerName`.
Детальную карточку получай отдельным запросом. При объединении нескольких меток
удаляй дубли закупок по `Id`, сохраняя их метки.

`markers` не принимает параметр `page` в этом снимке, хотя возвращает
`MarkerApiModelPagingModel`. Его `Items` содержат `Name` и `Id` метки.
Не добавляй недокументированный параметр пагинации.

## Карточки и результаты

Карточка `ExternalApiPurchaseModel` содержит `Title`, `InitialSum.Price`,
`InitialSum.Currency`, `Link`, `EtpLink`, `EisLink`, `ApplicationDeadline`,
`UpdatedDatetime`, `Organizer`, `Lots`, `Docs` и другие поля.
Не путай цену карточки с `SearchResultItem.MaxPrice` или ценой контракта.
В `Docs` ссылки находятся в `Url`, имена файлов — в `FileName`.

`PurchaseResults` содержит `Id`, `Link`, `Protocols`, `ContractProjects`,
`Contracts`. Участники и поставщики находятся во вложенных моделях протоколов
и контрактов. Уточняй структуру по ссылкам `$ref` в OpenAPI; плоского
`PurchaseResults.Winner` в схеме нет. Некоторые поля допускают `null`,
а некоторые используют `oneOf` с `BlurredApiSchema` для маскированных данных.

Получить нужную схему, не печатая весь файл:

```bash
python3 - <<'PY'
import json
from pathlib import Path
spec = json.loads(Path('references/zakupki.external_api-api.json').read_text())
print(json.dumps(spec['components']['schemas']['PurchaseResults'], ensure_ascii=False, indent=2))
PY
```

## Лимиты и виды ключей

`limitGroups` возвращает **массив** `ExternalApiLimitModel`, без `Items`:

- `LimitGroup`: `purchase`, `search`, `favorites`, `results`.
- `Modifiers`: `None`, `SearchParticipants`, `Snippets` — строковые значения.
- `AvailableRequests`, `TotalLimit`: остаток и общий лимит.
- `IsPeriodic`: при `true` лимит суточный; при `false` — на срок предоставления API.
- `SubscriptionStart`, `SubscriptionEnd`: сроки в UTC.

Общее описание говорит о сбросе суточного счётчика в 00:00 следующего дня,
но не называет часовой пояс сброса. Не считай его автоматически московским
и не применяй сброс к непериодическим лимитам. Не более пяти запросов одновременно.

Виды ключей из приложенного описания:

- Демонстрационный: фиксированный набор нетарифицируемых закупок.
  Поиск ограничен периодом **04.04.2022–08.04.2022**. Это не актуальные тендеры.
- Тестовый: полная база поиска, короткий срок действия и маскированные данные;
  выдаётся менеджером. Это другой вид доступа, не синоним демонстрационного ключа.
- Рабочий: доступ по тарифам, срокам подписки и лимитам.

Для `testpurchases` возьми разрешённый ID из описания метода, например
`0141600001021000268`; произвольный ID вернёт 404.
Тестовое избранное начинается с `2020-01-01T10:00:01Z`.
В демонстрационном режиме `markers` отдаёт фиксированные имена:
«Интересно», «Участвую», «Выиграл», «Проиграл», «Анализ».
Само наличие тестового пути не означает, что запрос разрешён без ключа.
